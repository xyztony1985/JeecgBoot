# 数据库规范

> 本文档定义本项目的数据库通用开发规范，包括表设计规范、字段规范、索引规范、Flyway 脚本规范等。

---

## 一、表设计规范

### 1.1 表命名

- 使用小写字母和下划线：`doc_template`、`doc_generate_log`
- 业务模块前缀：`{模块名}_{资源名}`
- 关联表：`{模块名}_{资源1}_{资源2}`
- 禁止使用 MySQL 保留字（如 `file`、`order`、`user` 等）

### 1.2 字段命名

- 使用小写字母和下划线：`create_time`、`file_url`
- 主键：`id`（VARCHAR(36)）
- 外键：`{关联表}_id`

### 1.3 索引命名

- 唯一索引：`uk_{字段名}`
- 普通索引：`idx_{字段名}`

### 1.4 建表模板

```sql
CREATE TABLE `{表名}` (
  `id` VARCHAR(36) NOT NULL COMMENT '主键',
  -- 业务字段
  `create_by` VARCHAR(50) DEFAULT NULL COMMENT '创建人',
  `create_time` DATETIME DEFAULT NULL COMMENT '创建时间',
  `update_by` VARCHAR(50) DEFAULT NULL COMMENT '更新人',
  `update_time` DATETIME DEFAULT NULL COMMENT '更新时间',
  `delete_by` VARCHAR(50) DEFAULT NULL COMMENT '删除人',
  `delete_time` DATETIME DEFAULT NULL COMMENT '删除时间',
  `owner_org_code` VARCHAR(64) DEFAULT NULL COMMENT '所有者部门编码',
  PRIMARY KEY (`id`),
  KEY `idx_xxx` (`字段名`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表描述';
```

## 二、Flyway 脚本规范

### 2.1 放置位置

所有 SQL 脚本统一放在项目根目录的 `sql/` 目录下：

```
{项目根目录}/sql/
```

**示例**：
```
d:\Code\JeecgBoot\sql\V20260720_0__attachment_create_sys_attachment.sql
```

### 2.2 命名规范

遵循 Flyway 标准规范：

```
V{YYYYMMDD}_{序号}__{模块名}_{操作}_{描述}.sql
```

#### 版本号前缀

- **`V` 开头**：版本化脚本，仅执行一次
- **`R` 开头**：可重复执行脚本（脚本改变后会重新执行）

#### 序号

- 同一天多个脚本时，序号从 `0` 开始递增：`_0`、`_1`、`_2`...

#### 双下划线

- 版本号和描述之间用双下划线 `__` 分隔

#### 示例

```
V20260720_0__attachment_create_sys_attachment.sql
V20260720_1__attachment_add_menu.sql
R__clean.sql
```

### 2.3 脚本模板

#### 建表脚本

```sql
-- 功能描述
-- 创建时间：{日期}

CREATE TABLE IF NOT EXISTS `{表名}` (
  `id` varchar(36) NOT NULL COMMENT '主键',
  -- 业务字段...
  `create_by` varchar(50) DEFAULT NULL COMMENT '创建人',
  `create_time` datetime DEFAULT NULL COMMENT '创建时间',
  `delete_by` varchar(50) DEFAULT NULL COMMENT '删除人',
  `delete_time` datetime DEFAULT NULL COMMENT '删除时间',
  `owner_org_code` varchar(64) DEFAULT NULL COMMENT '所有者部门编码',
  PRIMARY KEY (`id`),
  KEY `idx_xxx` (`字段名`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表描述';
```

#### 修改表结构

```sql
-- 功能描述：添加字段
-- 创建时间：{日期}

ALTER TABLE `{表名}` ADD COLUMN `{字段名}` {类型} COMMENT '{注释}';
```

#### 插入数据

```sql
-- 功能描述：初始化数据
-- 创建时间：{日期}

INSERT INTO `{表名}` (`id`, `字段1`, `字段2`) VALUES 
('1', '值1', '值2'),
('2', '值1', '值2');
```

### 2.4 注意事项

1. **使用 `CREATE TABLE IF NOT EXISTS`**：避免重复执行报错
2. **字段类型规范**：
   - 主键：`varchar(36)`
   - 时间字段：`datetime`
   - 文件路径：`varchar(500)` 起步（MinIO/OSS 返回完整 URL）
3. **字符集**：统一使用 `utf8mb4`
4. **注释**：每个字段必须有 `COMMENT`

### 2.5 执行方式

Flyway 脚本会在应用启动时自动执行，无需手动干预。

如需手动执行：

```bash
mysql -u {用户名} -p {数据库名} < sql/V20260720_0__attachment_create_sys_attachment.sql
```
