## 项目结构

```
/
├── .agents/              # AI 代理配置
│   └── skills/           # 技能定义
├── .trae/                # Trae IDE 配置
│   └── rules/            # 项目规则
├── spec/                 # 需求规格文档（按需求划分目录）
│   └── {feature-name}/   # 单个需求目录（kebab-case 命名）
│       ├── prd.md        # 产品需求文档
│       └── design.md     # 技术设计文档
├── jeecg-boot/           # 后端代码
└── jeecgboot-vue3/       # Web 前端代码
```
