## 快速开始

快速把项目成功跑起来，至关重要。

以下将按默认配置，启动项目。

默认配置是指 [配置文件](.env.development) 保持默认值，主要是后端接口默认为 `http://localhost:8080/jeecg-boot`。

### 环境准备

- Node.js 20+

    > 下载地址：<https://nodejs.org/zh-cn/download>

- pnpm 9+

    ```bash
    # 已有 Node.js 环境后，全局安装 pnpm
    npm install pnpm -g
    ```

- IDE：[VSCode](https://code.visualstudio.com/)

### 启动项目

- 安装依赖

    ```bash
    cd JeecgBoot/jeecgboot-vue3

    pnpm install
    ```

- 运行项目

    ```bash
    pnpm dev
    ```

- 访问 <http://localhost:3100/>，默认账号密码：`admin / 123456`


## 部署打包

```bash
pnpm build
```
